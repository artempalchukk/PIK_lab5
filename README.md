# Дашборд оцінювання мовних моделей

Лабораторна робота №5 — React-застосунок для візуалізації результатів оцінювання великих мовних моделей (LLM) із фокусом на якості роботи з **українською мовою**.

## Технології

| Технологія | Призначення |
|---|---|
| **React 18** + **TypeScript** | UI та типізація |
| **Vite 5** | Збірка та dev-сервер |
| **Tailwind CSS 3** | Стилізація, темна/світла тема |
| **Recharts** | Інтерактивні горизонтальні гістограми |
| **Lucide React** | Іконки |

## Функціонал

- **Картки підсумків** — найкраща модель, лідери за окремими метриками
- **Горизонтальна гістограма** — порівняння всіх моделей за 4 метриками одночасно (Recharts)
- **Сортована таблиця** — клік на будь-який заголовок колонки сортує дані ↑↓, прогрес-бари для швидкого сприйняття
- **Темна / світла тема** — автоматичне визначення за налаштуваннями ОС + ручне перемикання
- **Адаптивний дизайн** — коректне відображення від мобільного до широкого екрану
- **Hover-ефекти та анімації** — плавні переходи у картках і рядках таблиці

## Метрики оцінювання

| Метрика | Опис |
|---|---|
| **Фактологія** | Точність фактичних тверджень у відповідях |
| **Відсутність русизмів** | Чистота мови від небажаних запозичень з російської |
| **Літературна стилізація** | Якість та стилістична відповідність тексту |
| **Швидкість генерації** | Нормалізована швидкість отримання відповіді |

## Запуск проєкту

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера (http://localhost:5173)
npm run dev

# Збірка для production
npm run build
```
